# interval-projector

An independent **projection of the interval framework** (`Σca + θ = 1` and its
orthogonal form `(Σca)² + θ² = |UD|²`) and a candid analysis of where that work
genuinely connects to Eric Weinstein's **Geometric Unity (GU)** — and where it
does not.

This repository is part of the **Outpost System**. Its single page is built
directly from the project conversation *"Analyzing GU connections
independently."*

## The page

`index.html` is a self-contained static page (no build step, no dependencies).
It contains:

1. **The interval, projected** — the closed-interval (integral) form and the
   orthogonal (Pythagorean) form, with a live canvas projector that decomposes a
   unit interval into its resolved leg `Σca`, its structural leg `θ`, and the
   unifying-denominator hypotenuse `|UD|`.
2. **The question, asked independently** — does θ/ZTC/EEDF connect to GU?
3. **The two bridges that don't hold:**
   - *Q(√5) is the complexification* — **refuted.** Complexification adjoins
     `√(−1)`; `Q(√5)` adjoins `√5`, a real number. `Q(√5)` is a totally real
     field containing no square root of −1. The only shared content was the
     surface phrase "adjoin a square root."
   - *A SHA-256 replay hash answers the objection* — **category error.** A replay
     hash certifies reproducibility; the Shiab problem is whether a differential
     operator is *well-defined* on the relevant bundles. Deterministic code can
     faithfully compute something mathematically ill-defined.
4. **Confirmed vs. candidate ledger** — the framework's own epistemic discipline,
   preserved.
5. **Pending follow-ups** — T-18 ↔ GU-I Shiab uniqueness for E8; whether the
   ~0.053 gap is universal or E8-specific; θ_H ≈ 0.683 as an H-node parameter;
   stating how θ differs from entropy / measure-theoretic remainder / Gödel
   incompleteness.

## Finding, in one line

> **aesthetic**, but **not** at the level of **mathematics**.

- **Candidate** — intuition, sketch, or in development.
